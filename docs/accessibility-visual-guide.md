# Guía de Visibilidad y Accesibilidad Visual

## Objetivo

Mejorar la lectura y operación diaria del sistema para usuarios con baja visión o fatiga visual, manteniendo la estética actual del proyecto.

## Reglas aplicadas

- Encabezados de tablas en blanco o tonos de alto contraste.
- Labels de formularios con contraste alto.
- Texto secundario más claro que antes, evitando grises demasiado apagados.
- Placeholders visibles, pero diferenciados del valor real.
- Estados de foco siempre notorios en inputs, selects y textarea.

## Recomendaciones para futuras pantallas

- No usar gris oscuro en títulos o encabezados clave.
- Evitar bloques de texto extensos en tamaño pequeño.
- Mantener separación suficiente entre columnas de tablas.
- En datos críticos, preferir texto claro y directo antes que elementos decorativos.
- En modales, asegurar que título, acciones y error se distingan rápidamente.

## Casos especiales

- Si existen productos con nombres repetidos, mostrar siempre `SKU - Nombre`.
- Si una tabla tiene muchas columnas, priorizar contraste antes que compacidad extrema.
- Si un formulario tiene campos obligatorios, remarcar el label y mostrar errores específicos por campo.
